# BNDS AI普及计划

Sub2API をベースに、BNDS の名称と配色を採用した AI API プラットフォームです。

- リポジトリ：[Ctrl-Creeper/sub2api](https://github.com/Ctrl-Creeper/sub2api)
- リリース：[Releases](https://github.com/Ctrl-Creeper/sub2api/releases)
- コンテナイメージ：`ghcr.io/ctrl-creeper/sub2api`

導入・更新・ビルドの手順は [README.md（中国語）](README.md) を参照してください。
Web 管理画面の更新とロールバックには、この fork のリリースを使用します。
上流リリースの自動同期と競合通知については [同期ガイド](.github/upstream-sync/README.md)
を参照してください。
